## 2. Strict unseen-tool protection (build aborts on any violation)

Protected registry:
* BFCL v3, all 25 categories: 9,314 function entries plus all user questions;
* KrunBench v1 `final_protected` unseen tools: 1,695;
* the ToolACE items of the v0 `val_tools` / `holdout_tools` (the R2 tool benchmark): every gold and distractor tool
  (11,076 entries) and every query.

Totals: 10,128 unique names, 9,840 aliases, 6,236 queries. Match rules:
* exact normalized name;
* **alias**: camelCase / snake / kebab / dotted / spaced variants collapse to the same key;
* normalized description;
* equivalent description (char 5-gram Jaccard ≥ 0.8).

A tool that matches is removed from native lists. An item whose gold or any call matches is dropped. A protected query is
dropped. Final guards on 1,329,462 decisions:
* the builder's own check (0 violations);
* the independent `build_krunbench_v1.py --check`: **LEAKAGE = 0** (exact, normalized, near-duplicate, groups, tool
  id / name / description / equivalent).

The benchmark distractors include xLAM functions. That is why ~60% of xLAM golds are protected: the cleaner protocol
costs training data on purpose.

## 4. When2Call integration (tool OOD correction, public API unchanged)

When2Call is mapped to ordinary Krun questions:

| When2Call label | Krun decision(s) |
|---|---|
| tool call (pref "chosen") and every xLAM call item | **tool action** choice → `call_tool`; DO_NOT_CALL noul → **true**; routing choice → the gold tool |
| request for info (clarification) | tool action → `ask_clarification`; DO_NOT_CALL noul → **false**; routing choice → the single available tool (only when exactly one tool is listed) |
| cannot answer (no suitable tool) | tool action → `no_available_tool`; DO_NOT_CALL noul → **false**; **native irrelevance** choice (unanswerable → abstention by margin) |

* **Tool action.** A 3-candidate choice with described actions; the context lists the available functions. 48,961
  decisions carry an action label: ask 25,291, call 15,911, no tool 7,759.
* **DO_NOT_CALL.** The proposition "One of the available functions can be called right now with the information given."
  (18,922 decisions).
* The public abstention stays the top1 − top2 margin; no answerability head was reopened.

## 5. How much xLAM contributes (the owner asked explicitly)

* Decisions: **122,207 of the 286,516 new decisions (42.7%)**. Of those, 120,143 are xLAM routing/action/noul and
  2,064 are xlam-irrelevance.
* Queries: 23,941 real xLAM queries survive protection (of 60,000).
* **Tools: 1,963 xLAM tool names survive, and only 84 of them appear in no other source.** ToolMind and When2Call
  reuse the xLAM tool pool. So xLAM adds **query volume and phrasing, not API diversity**.
* The measured effect is the ablation probe: `results/v1/r2/XLAM_ABLATION.md`.
