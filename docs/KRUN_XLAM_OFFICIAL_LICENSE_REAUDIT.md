## 3. Correction of the brief's premise

The brief assumed that only the mirror contains "research purposes only". **The official card contains the same
sentence**, in the same document that declares CC-BY-4.0. The conflict is therefore in the official source itself.

## 4. Assessment

* **For CLEARED:**
  * the machine-readable license is CC-BY-4.0, which permits commercial use;
  * the gate asks only for license acknowledgment + citation;
  * NVIDIA redistributes an xLAM-derived dataset (When2Call train) as CC-BY-4.0, "ready for commercial use". That is
    evidence of another large company's reading.
* **Against:**
  * an explicit, current "research purposes only" statement by the licensor, in the official card;
  * AUP references;
  * the sibling model releases are non-commercial;
  * the commit history cannot be checked without accepting the terms.
* A material doubt remains. Under the project's rule (as for XNLI / PAWS-X) that means **no engineering clearance**.
  Only the owner, possibly after asking Salesforce, can clear it.

## 8. Owner decision (2026-09-28)

**The owner chose option 1: xLAM is CLEARED_FOR_V1 by owner decision (`approved_by_owner`).** The engineering finding
stays `OWNER_REVIEW_REQUIRED`: the official card has a research-only statement. The owner accepts the risk, as already
done for v0.3 in production. By the same decision, When2Call train and ToolMind graph_syn are included; ToolMind items that
use any Glaive-v2 function are filtered out, because Glaive stays `PENDING_LICENSE_HISTORY_REVIEW`.

The local copy of the xLAM rows is the argilla re-host (`origin == "xLAM"`). The official files need gated acceptance
in the owner's HF account, which Claude did not do on the owner's behalf. Swapping to the official file later is a
data-identical re-download and changes no training decision.
